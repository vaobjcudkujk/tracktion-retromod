## Overview

RetroMod is a collection of vintage chorus, flanger, and vibrato effects modeled on classic hardware including the Roland CE-1, MXR Flanger, and Boss BF-2 with authentic circuit character.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Tracktion RetroMod** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **CE-1 Chorus** | Accurate chorus model matching Roland CE-1 bucket-brigade circuit |
| **MXR Flanger** | Classic MXR-style flanger with manual, envelope, and LFO modes |
| **BF-2 Model** | BOSS BF-2 flanger emulation with feedback and regeneration control |
| **Stereo Spread** | Adjustable stereo spread for wide spatial chorus effects |
